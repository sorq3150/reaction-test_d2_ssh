# 変更点（第5段階 → v0.6.0）

## 参加上限
- 既定100・範囲10〜300・`MAX_PARTICIPANTS` を維持。範囲外/不正値は補正して起動ログに警告。
- `frontend/css/server.js`（古い10台制限の旧サーバー）を**削除**（静的配信で公開されていた）。コード全体を検索し、他に10台制限の残存なし。
- ホスト画面の上限表示を、HTML固定値からサーバーの値（`/config`・各イベント）に変更。`host.html` の初期表示は「0 / — 台」。

## 不具合修正
- **CSV出力が壊れていた**（BOMと改行が文字としての `\uFEFF` `\r\n` になり、全行が1行に連結）。サーバー側出力でBOM付き・CRLFに修正。
- 不正payloadでサーバーが落ちる問題（未認証DoS）を修正。
- 結果の送信確認が不十分で、サーバーが受理しない結果があっても端末が成功扱いにする問題を修正（受信件数の照合・再試行）。
- 次の試行の通知が、直前の試行のタイムアウト記録より先に届いて**タイムアウトの記録が消える競合**を修正（サーバーの次試行まで1.5秒の余裕を追加、端末側でも取り逃がし試行を補完）。
- 途中参加者が設定回数を測定できなかった問題を修正（参加者ごとの測定範囲を管理）。
- 一時停止・切断・タブ非表示・再接続後の取り逃がし試行を、無効データ（理由付き）として保存。
- 測定を終了後に再度開始すると結果の試行番号が重なる問題を、`run`（測定回）番号で区別して解決。
- 再接続のたびにオプション画面が開き直る問題、参加時にオプションが再度開く競合を修正。
- 部屋終了時に参加者が未送信の結果を送れずに失う問題を修正（終了通知後に送信してからホームへ）。退出前にも送信。
- 再接続時にまだ予定時刻が先の試行を再通知（時計同期の完了を待ってから適用）。
- `index.html` の「測定機能はまだ実装されていません」を修正。

## 追加・改善
- 測定記録項目の拡張（scheduled_time / local_change_time / input_time / clock_offset / RTT / sync_quality / frame_delay / visibility_state / browser / os / device / input_type / invalid_reason）。
- 時刻基準を `performance.timeOrigin + performance.now()` に統一（システム時計の変更の影響を受けない）。切替は予定の約120ms前から `requestAnimationFrame` で最も近いフレームを選択。
- 入力方式を `touch` / `mouse` / `pen` / `keyboard` に細分化。
- ホスト画面: 最小・最大・標準偏差、早押し・タイムアウト・無効数、参加者別・入力方式別の集計。結果表は先頭500件、集計・出力は全件（サーバー側集計）。
- 結果の出力をサーバー側のストリーミングへ（CSV/ExcelJS）。大量データでもブラウザが固まらない。
- ホスト画面に「新しい部屋を作成」「過去の部屋を開く」を追加（従来は部屋終了後に新規作成できなかった）。
- 通信削減: ホストへの更新通知を250msにまとめ、SQLite書き込みも250msにまとめ。試行通知は対象の参加者のみへ送信。測定中の結果送信は無し。
- `/health`（接続数・メモリ）、メモリ監視ログ、SIGTERM時のデータ保存。
- SQLite: 集計用の列と索引を追加（旧DBは自動移行・データ削除なし）、DBファイルのパーミッション600、結果の取得はカーソル方式。

## 仕様の変更（既存仕様との差異）
- 測定中・**一時停止中**の設定変更を不可にした（旧版は一時停止中は変更可）。参加者ごとの測定範囲との整合のため。
- 未使用だったイベント `participant:trial-result`（任意文字列を保存するだけ）を削除。画面から使われていませんでした。
- 入力方式の値 `pointer` を `touch`/`mouse`/`pen` に変更。
- `host:get-results` は `offset` ではなく `cursor`（カーソル）方式。

## 今後の改善案
- 実機（Chromebook/スマホ）での計測精度の検証と `sync_quality` 閾値の調整。
- 外部オブジェクトストレージ/Postgres への定期バックアップ。
- 未終了の放置部屋の自動クローズ、参加時の簡易パスコード。
- Express 5 への移行（互換性試験後）、ExcelJS代替の検討（更新が止まっているため）。
