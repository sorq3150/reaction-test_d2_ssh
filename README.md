# 反射神経測定アプリ 第5段階

第4段階の測定機能を引き継ぎ、SQLiteによる永続保存、サーバー再起動後の部屋復元、結果送信の分割・再試行、参加上限の拡大を追加した版です。

## 起動
Node.js 18以上で `npm install` → `npm start`。ローカルでは既定で `data/reaction-test.sqlite` に保存します。

## Renderへのデプロイ
- Build Command: `npm install`
- Start Command: `npm start`
- Render Web ServiceにPersistent Diskを追加し、Mount Pathを `/var/data` に設定
- Environment Variables: `DB_PATH=/var/data/reaction-test.sqlite`、`MAX_PARTICIPANTS=100`
- `MAX_PARTICIPANTS` は10〜300で設定可能。初期値は100です。

**重要:** Persistent Diskを設定しない場合、Renderの再デプロイ・インスタンス交換などでSQLiteファイルが失われる可能性があります。データ保持には永続ディスクを必ず設定してください。SQLiteは単一インスタンス用です。複数インスタンスへ水平スケールする場合はPostgreSQL等へ移行してください。

## 第5段階の追加内容
- SQLiteデータベースへの測定結果保存。部屋を終了しても結果データは保持。
- 部屋・ホストトークン・参加者トークン・設定・試行番号の保存。
- サーバー再起動時に未終了の部屋を復元。測定中だった部屋は安全のため一時停止状態で復元。
- recordIdを主キーにした重複登録防止。
- 参加者の結果送信を100件ずつに分割し、各バッチを最大3回再試行。
- ホストの結果取得を最大5,000件ずつページ取得。画面表示は先頭500件に制限し、集計・CSV・Excel出力は取得した全件が対象。
- 参加上限は既定100台、環境変数で最大300台まで設定可能。
- 接続要求の簡易レート制限、Socket.IOのメッセージ上限縮小、圧縮無効化。

## 負荷と研究利用について
- 本版は同時接続100台・300台での実機負荷試験を完了していません。設定上の上限は安定動作保証ではありません。
- 最初は10台、次に30台、50台、100台と段階的に試験してください。300台は上限値であり、一般的なRender構成で推奨する同時接続数ではありません。
- 参加者の反応時間は各端末内で計測し、測定中に試行ごとの結果をサーバーへ送信しません。終了後に100件ずつ送信します。
- 100台×500試行では最大50,000件になります。端末側のIndexedDB容量、ブラウザ、Wi-Fi、サーバープランを含む実環境での試験が必要です。
- 画面の物理的な発光時刻を直接測定するものではありません。ディスプレイ・OS・入力機器の遅延は残ります。
