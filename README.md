# 反射神経測定アプリ 第4段階

第3段階の測定機能を引き継ぎ、測定結果のサーバー回収、集計、CSV/Excel出力を追加した試作版です。

## 起動
Node.js 18以上で `npm install` → `npm start`。Renderでは Build Command=`npm install`、Start Command=`npm start`。

## 画面
- `/` トップ
- `/host` ホスト
- `/participant` 参加者

## 第4段階の追加
- 参加者端末のIndexedDBから、測定終了後に結果をサーバーへ送信
- サーバー側でrecordIdを使って重複登録を抑止
- ホストによる結果取得
- 有効データ数、平均、中央値、標準偏差の表示
- CSV出力、SheetJS CDNを利用したXLSX出力

## 重要な制限
- サーバーの結果保存先はメモリです。Render等の再起動・スリープ・再デプロイで消えます。永続DBは未実装です。
- 結果送信はセッション終了イベントを受け取った端末が接続中であることが前提です。切断中の端末は再接続後に手動で再送する仕組みが未実装です。
- Excel出力は外部CDNが読み込める場合のみ動作します。CSV出力はブラウザ標準機能です。
- 途中参加者の回数保証、複数端末での厳密な同期、描画遅延/バックグラウンド判定、物理的な画面発光時刻の測定は未完成です。
- 複数端末での実機試験・研究用途の精度検証は未実施です。本採取前に必ず試験してください。
- サーバーは認証トークンを利用しますが、公開前にHTTPS、アクセス制御、データの取扱いを確認してください。
