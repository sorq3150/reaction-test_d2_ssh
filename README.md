# 反射神経測定Webアプリ（第2段階）

第2段階では、部屋作成・参加者登録・参加者一覧・途中参加・切断表示・再接続の基本機能を実装しています。

## 必要環境
- Node.js 18以上
- npm
- Chrome / Chromium系ブラウザ推奨

## 起動方法
1. このフォルダでターミナルを開く
2. `npm install`
3. `npm start`
4. ブラウザで `http://localhost:3000` を開く

同じネットワーク内の別端末から試す場合は、サーバーPCのローカルIPアドレスとポート3000を使用してください。学校や家庭のネットワーク設定によっては接続できない場合があります。

## 操作
- 最初の画面で「ホスト」を選ぶと部屋を作成できます。
- 参加者端末では「参加者」を選び、6桁の部屋番号・参加者名を入力します。
- ホスト画面には参加者一覧と接続状態が表示されます。
- 参加者は測定中でも接続できます。第2段階では「次の試行から参加予定」として登録します。実際の試行進行・回数保証は第3段階以降で実装します。
- 再接続は同じブラウザに保存した参加者トークンを使います。同じ端末・同じブラウザのサイトデータを消去すると復帰できません。

## 第2段階の実装範囲
- 6桁の部屋番号（重複チェック）
- 1部屋あたり最大10参加者
- ホスト用トークンと参加者用トークンによる権限確認
- 参加者IDと参加者名の分離
- 参加者一覧のリアルタイム更新
- 切断状態の表示
- 参加途中の接続受付
- 同一ブラウザからの再接続
- ホストによる参加者の退出処理
- ホストによる部屋終了

## 未実装・制約
- 部屋情報はサーバーのメモリ内だけに保存されます。サーバー再起動・スリープ・デプロイで部屋情報は消失します。
- 認証トークンはブラウザのlocalStorageに保存します。研究本番ではHTTPSを必須にし、トークンの扱い・有効期限・保存方法を追加検討してください。
- 第2段階では測定、時刻同期、IndexedDB、結果回収、CSV/Excel出力は未実装です。
- 途中参加者の「次の試行から参加」表示のみ実装しています。参加者ごとの測定回数保証は測定エンジン実装時に追加します。
- 参加者名の重複は同一部屋内で拒否します（大文字小文字・前後空白を正規化）。
- 部屋番号は推測される可能性があるため、番号だけでは参加者一覧やデータにアクセスできません。トークン認証も必要です。

## Render等への公開
RenderなどでNode.js Web Serviceとして公開する場合：
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: Node
- HTTPSはホスティングサービス側の提供機能を利用してください。

無料プランのスリープ・再起動・通信制限は測定の安定性に影響します。同期精度の検証前に、本番研究データの取得へ使用しないでください。
